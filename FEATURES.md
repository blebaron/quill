# Feature tracking

Quill tracks feature ideas, active work, and completed work in the local Beads
issue database. Use `bd ready` for unblocked work, `bd list --all` for issue
history, and `bd show <id>` for full requirements and decisions. The migration
of this former backlog is recorded in `quill-obg`.

The `.issues/` documents retain incident analyses and the original speaker
catalog request as reference material; their current status lives in Beads.
