# Quill v0.1.0

## What changes

This source release pins FluidAudio 0.17.7 and adds requested-count safety
checks. It addresses post-refinement speaker-count collapse and corrects
misleading exact-count guidance. `quill --version` reports `0.1.0`.

For `rediarize`, requests for missing tracks or nonpositive counts, diarization
errors, absent results and mismatched returned timeline counts fail without
replacing existing transcript/speaker files. Automatic fallback remains as
before. The default English transcription model remains Parakeet TDT v2.

## Before rerunning a session

- Back up the **whole session folder** first, outside the configured recordings
  root so the pending-session scanner cannot pick up the backup.
- Reruns also transcribe again: text, timestamps, labels and partitions can
  change. On success, generated transcript and speaker files are overwritten.
- A speaker count is a target, not an identity or voice-separation guarantee.
  Validate identities before using person-attributed statements or actions.
- Old sessions are not automatically migrated. Full uncertain-candidate
  retention/review is not implemented; E5RT warnings remain unresolved.

## Upgrade

Build from the published `v0.1.0` tag/source archive in a separate checkout,
not an arbitrary working copy or a directory backing the installed binary.
macOS 15+ is required. Validation so far is on Apple Silicon/Swift 6.4;
other environments are not independently certified by that test result.

Model caches were ready on the validation machine; a fresh installation may
download models. Doctor's system-audio warning is not permission certification.
Run an explicitly chosen nonsensitive capture test before relying on the
upgrade for an important meeting.

Finish any recording and wait for transcription to complete. Quit a manually
started Quill before running this fail-fast upgrade block. It unloads a loaded
LaunchAgent and restarts it only if it was loaded before the upgrade. A failed
build, backup, verification or install stops before later replacement steps.
Each backup has its own directory; later upgrades do not overwrite it.

```sh
(
set -e
swift build -c release
BIN_DIR="$(swift build -c release --show-bin-path)"
test "$("$BIN_DIR/quill" --version)" = '0.1.0'
"$BIN_DIR/quill" doctor
SERVICE="gui/$(id -u)/com.digimata.quill"
WAS_AGENT_LOADED=0
if launchctl print "$SERVICE" >/dev/null 2>&1; then
  WAS_AGENT_LOADED=1
  launchctl bootout "$SERVICE"
fi
if [ -e /usr/local/bin/quill ]; then
  BACKUP_ROOT="$HOME/Library/Application Support/quill/rollback"
  mkdir -p "$BACKUP_ROOT"
  BACKUP_DIR="$(mktemp -d "$BACKUP_ROOT/$(date -u +%Y%m%dT%H%M%SZ).XXXXXX")"
  cp -L /usr/local/bin/quill "$BACKUP_DIR/quill"
  cmp /usr/local/bin/quill "$BACKUP_DIR/quill"
  (cd "$BACKUP_DIR" && shasum -a 256 quill > quill.sha256)
  printf 'Rollback binary saved to: %s\n' "$BACKUP_DIR"
fi
sudo mkdir -p /usr/local/bin
sudo install -m 755 "$BIN_DIR/quill" /usr/local/bin/quill.new
cmp "$BIN_DIR/quill" /usr/local/bin/quill.new
sudo mv -f /usr/local/bin/quill.new /usr/local/bin/quill
test "$(/usr/local/bin/quill --version)" = '0.1.0'
if [ "$WAS_AGENT_LOADED" = 1 ]; then
  /usr/local/bin/quill install --launch-at-login
fi
)
```

If you run Quill manually, start it yourself when ready. Enabling launch at
login for the first time is a separate optional choice, not part of replacing
the binary.

Keep the bundle identifier and LaunchAgent label unchanged. If macOS prompts
for permissions, review them normally; do not bypass its security checks.

## Rollback

Stop Quill only after recording/transcription finish. Quit a manually started
application. Set `BACKUP_DIR` to the exact directory printed during the desired
upgrade, then restore that identified binary. Do not select a backup by guess
or overwrite it with another build.

```sh
BACKUP_DIR='/path/printed/during/the/upgrade'
(
set -e
test -f "$BACKUP_DIR/quill"
(cd "$BACKUP_DIR" && shasum -a 256 -c quill.sha256)
SERVICE="gui/$(id -u)/com.digimata.quill"
WAS_AGENT_LOADED=0
if launchctl print "$SERVICE" >/dev/null 2>&1; then
  WAS_AGENT_LOADED=1
  launchctl bootout "$SERVICE"
fi
sudo install -m 755 "$BACKUP_DIR/quill" /usr/local/bin/quill.new
cmp "$BACKUP_DIR/quill" /usr/local/bin/quill.new
sudo mv -f /usr/local/bin/quill.new /usr/local/bin/quill
if [ "$WAS_AGENT_LOADED" = 1 ]; then
  /usr/local/bin/quill install --launch-at-login
fi
)
```

Otherwise build the previous release in a separate checkout. For this first
tagged release, the prior source baseline is commit
`910abdac201188eff51cb22bee8b682da384e7aa` (FluidAudio 0.15.5).

Rollback restores software, **not regenerated transcripts**. Restore the saved
session artifacts separately if needed. Never delete the original audio to
reset processing.

## Validation and scope

The final preparation passed 28 tests in both debug and release configurations,
a production build, version/embedded-metadata checks and synthetic invalid-request
CLI checks. The exact release commit must also pass the isolated checks in
[RELEASING.md](../../RELEASING.md) before publication. Validation was on
arm64 macOS 26.6.2 with Apple Swift 6.4.

The maintainer explicitly accepted the existing validation for this release
without a new capture/permission smoke test. No fresh capture certification is
claimed. Publication does not install or restart Quill, migrate sessions or
promote private calibration outputs. The narrow collapse case is accepted;
broader processing-health/candidate-review work remains open.
